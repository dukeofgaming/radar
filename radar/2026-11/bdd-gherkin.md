BDD here means one Gherkin file per slice, run as the acceptance test. [scriptorium](https://github.com/dukeofgaming/scriptorium/pull/5), the Markdown sync CLI, and [detent](https://github.com/dukeofgaming/detent/tree/cucumber), the BPMN converter, both use the Rust cucumber crate. A private bibliography app uses playwright-bdd for the same shape.
