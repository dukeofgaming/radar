Changesets is how the npm packages get a version and a changelog. [ab-ui](https://github.com/dukeofgaming/ab-ui), the component library, and [ab-app](https://github.com/dukeofgaming/ab-app), the Next.js starter, both publish that way from GitHub Actions.
