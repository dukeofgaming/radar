Documentation as code means the write-up lives in the repository and is reviewed like code. At Flexion that replaced Visio and Lucid for design notes. [scriptorium](https://github.com/dukeofgaming/scriptorium/pull/7) is a CLI that copies one Markdown file to Jira, Confluence, Google Docs, and GitHub issues. This radar is the same idea applied to a technology list.
