GitOps means a merge updates the running system, instead of a person applying manifests by hand. The 2021 interview app [flexion-unitconverter](https://github.com/dukeofgaming/flexion-unitconverter), a unit converter, used Flux to do that for Kubernetes. [ipfs-metadata](https://github.com/dukeofgaming/ipfs-metadata), a Go API that stores IPFS metadata in Postgres, later used Terraform in GitHub Actions for the same idea on AWS.
