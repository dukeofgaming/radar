isomorphic-git is a Git implementation that runs inside the app, so the app can commit without a shell. A private branch viewer uses it for local writes, and a private bibliography app uses it to store a BibTeX library. It is declared in [ab-app-brands](https://github.com/ab-internal/ab-app-brands) and not imported there.
