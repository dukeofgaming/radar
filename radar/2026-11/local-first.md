Local-first means the record lives on the machine and syncs later, which is the shape of this year's private apps. A spend ledger uses SQLite. A bibliography app and a branch viewer use isomorphic-git. A knowledge notebook stores Markdown. The 2021 GitOps note used the same phrase for a deploy loop, which is a different idea.
