Python is the language of the audio tool and one take-home API. [socioscope](https://github.com/dukeofgaming/socioscope) is a command-line program that labels speakers with pyannote and transcribes with whisper.cpp. [hotto-test](https://github.com/dukeofgaming/hotto-test) is a survey app: a Python API in front of MySQL and a React page. [fd-python](https://github.com/dukeofgaming/fd-python) is a handful of practice scripts.
