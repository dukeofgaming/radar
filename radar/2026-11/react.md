React is the UI library across a five-year stretch, from a 2021 interview app to the current design system. [flexion-unitconverter](https://github.com/dukeofgaming/flexion-unitconverter) is that interview app, a unit converter. [ab-ui](https://github.com/dukeofgaming/ab-ui) is a component library for age checks, buttons, inputs, and data tables. The Next.js sites and the private desktop shells (a branch viewer, a bibliography app, and an org map) use the same library.
