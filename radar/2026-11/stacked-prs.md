Small stacked pull requests means one branch per slice, based on the previous branch, instead of a long-lived branch. A private desktop app exists to read that stack, and its own workflow is written down as an architecture decision. The same shape shows up as the cursor branches on [scriptorium](https://github.com/dukeofgaming/scriptorium/pulls), the Markdown sync CLI.
