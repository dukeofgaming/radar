Tailwind is the styling layer for the design system and the sites around it. [ab-ui](https://github.com/dukeofgaming/ab-ui), the React component library, uses Tailwind 4, and so do [ab-app](https://github.com/dukeofgaming/ab-app) and [ab-app-brand-site](https://github.com/dukeofgaming/ab-app-brand-site). The private desktop apps use it too.
