Terraform is how the cloud accounts were described as code, first on the Flexion Google Cloud project and later for a small AWS deploy. In December 2021 he [posted on X](https://x.com/dukeofgaming/status/1471203228373196813) about Terraform's rule that error text should read like plain English. [ipfs-metadata](https://github.com/dukeofgaming/ipfs-metadata) is a Go API that saves IPFS metadata into Postgres, and its Terraform modules create ECS, RDS, and an ALB.
